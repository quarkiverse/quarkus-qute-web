# Attic

Non-build material kept next to the image extension:

- `dynamic/`: the removed runtime (dynamic) image resolution extension, with a README on why and how to restore.
- `build-time-resolution/`: the design document for build-time resolution of expression image sources (qute-web contract plus the Roq implementation) and the JBang POC (`ImagePoc.java`) that validated it against the Roq blog.
